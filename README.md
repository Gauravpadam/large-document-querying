# large-document-querying

`standard-treatment-guidelines.pdf` is a document which is to be analysed, and a chat system is to be built on top of it.

The pdf contains:
1. Text
2. Tabular data
3. Images
4. Negative space

Functional requirements:
1. The system should accurately respond 80% of the times.
2. The system should stick to the knowledge from document.

NF requirements:
1. System should be scalable, irrelevant to document size
2. System should be traceable
